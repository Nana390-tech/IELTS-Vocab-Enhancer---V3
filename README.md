# Vocabulary Kingdom V4

A colorful fantasy-game redesign of IELTS Vocabulary Enhancer for Band 6–6.5 learners.

## Upload to GitHub
Upload everything in this ZIP to the repository root, including the `assets` folder. Keep `vocabulary.json` beside `index.html`. Publish GitHub Pages from `main` and `/(root)`.

## V4 additions
- Full illustrated enchanted-door hero image
- 20-door fantasy learning map
- Royal Road progress journey
- Animated adventurer progress marker
- Reward gallery with 10 collectible titles
- Grand Master Chamber progress
- Gamified weak-word rescue mission
- Fantasy-styled category challenges
- Illustrated collectible certificates with unique titles by category
- Responsive mobile design
- Existing 300-word database, Arabic support, review engine, printing, CSV, and JSON backup retained
